What do the scores mean?

Performance compares CPU/GPU power with your reference PC in Settings (100% = equal). The deal score ranks value within your available listings (100 = best for your goal). Prices deduct any included setup. Scores help compare listings; check condition and seller details before buying.

Benchmark notes & score definitions

CPU percentages are relative to your yardstick and use PassMark single-/multi-thread evidence. Gaming profiles use resolution- and graphics-mode-specific GPU game-suite indices where available; PassMark is shown separately. GPU suite FPS is an estimated multi-game geometric mean, not an individual-game prediction. “Proxy” means no curated CPU single-thread score is available, so the model falls back to CPU Mark. Evidence quality is shown per row. Value / 100 is normalized against the best available listing.

Your yardstick

The PC that counts as 100%. Every listing is scored as a % of it. Gaming GPU comparisons use compatible native-resolution test suites when available; CPU performance remains a synthetic benchmark-based estimate. Most people can leave this alone.

Performance profile

Choose a workload to change the performance index. Gaming profiles use Tom’s Hardware native-resolution GPU game benchmarks where the GPU and reference GPU are covered; other profiles use PassMark G3D Mark. The separate value score remains market-price based.

GPU suite FPS is estimated from Tom’s Hardware’s published multi-game geometric-mean FPS for the selected resolution and mode. It is a suite-wide average, not a specific game’s FPS or a guarantee for the complete PC; the source testbed uses a Ryzen 7 9800X3D and excludes upscaling/frame generation. Unsupported GPUs show N/A instead of an invented estimate.

How value is weighted

Value uses the price shares of a typical build, then divides by effective price after any setup deduction.

How scoring works

Performance compares a PC's CPU and GPU with the yardstick PC for the workload you picked in Settings. Value is separate: CPU, GPU, RAM and storage are weighted by what a typical 2026 build spends on each (DDR5 counts for more than DDR4 because it costs more), then divided by the price minus an included setup, so a cheaper PC can beat a stronger one. On the Compare tab, Daily driver ranks by performance per euro for your workload, Resale profit by how much hardware (at market part prices) each euro buys, and Both by a mix that only rewards listings good at both. Assumed RAM/SSD values are marked with ~.
